# TypeX — Typing Arena

Neon-blue gaming-inspired typing practice website.

## Features
- 15, 30 and 60 second typing tests
- Live WPM, accuracy, errors and timer
- Character-by-character typing feedback
- Personal best and test count saved in browser localStorage
- Daily practice mission and speed milestone
- Responsive mobile and desktop layout

## Run
Open `index.html` in a browser. No build tools or dependencies are required.

## Enable GitHub Pages
1. Open repository Settings → Pages.
2. Choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Your site should publish at https://rajdivyam55-dev.github.io/Type-X/

This is a front-end project. Stats are saved in the current browser; accounts and an online leaderboard are not included yet.
